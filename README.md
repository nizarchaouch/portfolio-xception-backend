This repository contains the backend of **Portfolio Xception**, a full-stack web platform for professional portfolio creation, job offer management, and job applications.

The backend provides REST APIs for authentication, user management, recruiters, candidates, job offers, applications, portfolio templates, notifications, and CV management.

## Backend Responsibilities

- User authentication and authorization
- Recruiter and candidate management
- Job offers management
- Applications management
- Portfolio templates management
- Notifications handling
- CV upload handling
- Database communication
- REST API endpoints

## Tech Stack

- Node.js
- Express.js
- MongoDB
- REST API
- JSON

## Getting Started

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- MongoDB

### Clone the repository

```bash
git clone https://github.com/nizarchaouch/portfolio-xception-backend.git
cd portfolio-xception-backend
```

### Install dependencies

```bash
npm install
```

### Run the server

```bash
npm run dev
```

### Run in production

```bash
npm start
```
